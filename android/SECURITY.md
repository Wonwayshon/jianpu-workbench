# 1.19.0 安全设计与验证边界

## 凭据与发布

API Key 和 WebDAV 密码以 AES/GCM 保存到私有 SharedPreferences；加密密钥由 Android Keystore 管理，凭据 ID 是附加认证数据。JavaScript 不能读取已保存的明文，原生请求按凭据标识加入鉴权。API 限定完整地址，WebDAV 限定 HTTPS 同源目录；不跟随重定向。更换服务地址或账号必须重新输入凭据。旧网页配置安全迁移失败时保留旧数据并提示；迁移成功后移除网页明文。删除配置同时删除凭据。浏览器版采用内存会话存储。

发布 manifest 禁用调试、明文流量、云备份和设备迁移；WebView 调试关闭。签名沿用既有证书。签名私钥不在 APK 或源码交付包中；不共享 work/android-signing。没有采用商业加壳；HTML/JS 仍可从 APK 提取。加密不能保护已被控制或 root 后被动态注入的运行环境，CSP 也不能替代所有输入验证。

## WebView 与导入

只在本地 index.html 启用原生接口，外链交给系统浏览器。WebView 外部资源请求被阻止，CSP 仅允许本地/哈希脚本，禁止 iframe/object/表单外发；样式、图片、音频和 PDF worker 按本机功能需求开放 data/blob。文件使用系统选择器，无全盘权限。

ZIP 总大小/解压总量 300 MB、单项 80 MB、最多 2000 项，校验 CRC、目录边界和路径，拒绝重复路径/分卷/加密。Word XML 8 MB、拒绝 DTD/实体，图片最多 60 张且输出总像素受限。分享码解压最多 2 MB、最多 300 页。PDF 最多 2000 页，加载/渲染默认 30 秒超时。图片缩小后检查像素上限；不能保证系统解码器对所有极端图片都不出现瞬时内存峰值。

网络最多 4 个原生并发请求；模型响应 8 MB、传输响应 300 MB、文字解析 25 MB；有连接/读取超时。用户选择的服务仍需可信：会收到主动提交的图片/文字或谱库。每个识别服务首次发送图片时提示。应用不内置开发者付费密钥。

## 存档恢复与同步

IndexedDB v3 保留旧存档和原文件；旧版快照与覆盖在同一事务中。每份 3 版、合计 100 版，恢复创建副本。清空恢复区时，仅清理没有活动存档引用的原文件。自动淘汰快照后原文件可能暂留，清空恢复区统一清理。

同步覆盖/删除远端存档前获取远端副本，失败则中止；远端原文件不随单份存档删除，避免共享附件被误删。远端可能残留无引用文件。清单支持 ETag 条件写入，但这不是跨多文件的分布式事务，也不保证多个设备同时修改时完全无冲突。建议交替同步并保留独立 ZIP 备份。

恢复区在本机，不包含在普通 ZIP 备份内；ZIP 包含活动存档及原文件，不包含凭据，且没有加密。设备损坏/卸载/清除数据会使本地恢复区不可用。

## 已执行与待实测

已执行：凭据迁移及迁移失败保留、原生鉴权地址约束；真实 IndexedDB API 的模拟实现下测试 v2 升级、事务回滚、恢复副本、附件保留/清理；损坏 ZIP、路径/大小/CRC、QR 解压上限和超时；既有乐谱/总谱/存档回归；Java/DEX/资源编译及 APK 签名、版本与资产一致性校验。

待 Android 设备验证：旧版本覆盖安装后的凭据迁移、重启后识别与 WebDAV、配置更换地址；PDF/图片/Word 实际导入（含 CSP worker）、扫码与麦克风授权；系统分享/文件保存；无网络/无空间/Keystore 失效提示。这是针对已知入口的加固，不是完整渗透测试或安全认证。
