界面全面改版：更简洁的现代风格，可在「设置 → 外观」更换主题色。手机底部导航改为 转谱 / 谱库 / 练习 / 工具 / 设置，换算、指法、调音、二胡归入「工具」；平板使用侧边图标栏，电脑使用分组侧边栏。

转谱：谱面改为「简谱 / 五线谱」加「调」菜单（原调、音名谱、转调）；图片识别移入「导入 / 识别」弹窗，提示词按所选范围与类型一键复制；新增行号、原图对照、符号快捷输入和底部播放栏；文本有误时保留上次正确的谱面并可一键跳到出错行；总谱声部的显示、发声与音色集中到「声部」面板。

换算改为点选式按钮，并可在「选篠笛」与「我的篠笛能吹什么调」之间切换；指法表按音区切换并提供详情面板；谱库改为列表加详情；调音器新增长音稳定度显示。

Android 沿用原发布签名。macOS 为 Apple Silicon 版本，尚未经过 Apple 公证；Windows 安装程序未做商业代码签名。
