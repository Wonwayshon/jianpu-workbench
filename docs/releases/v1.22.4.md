二胡指法可以手动修改：点谱面上的二胡小字，或双击音符选「编辑指法」，可调整出弓 / 进弓、内外弦、指法、上下滑换把，以及滑、伸和隐藏。改动写在乐谱文本里该音之后（如 3'/[外二⊓]），随存档、分享和导出 PDF 一起保存；没改的项仍按自动推算。可单个或整首「恢复自动」，均需二次确认。

双击音符弹出「从这里开始播放 / 编辑 / 编辑指法」菜单；「编辑」会定位到该音的文字，全屏下进入编辑模式。

二胡标记更省空间：有换把箭头时不再写「滑」，颤音只标按住的手指。同音换弦（外弦空弦与内弦四指）只用于同一小节里单独连成一组的两个音，跨小节或 3355 这类快速音型不再强制换弦。
