界面按设计稿逐页校对：转谱桌面版改为整屏工作台（顶栏显示调号、拍号、速度与音符数，左侧文本、右侧谱面各自滚动，播放条贴底），桌面左侧在转谱页收为窄图标栏；手机播放条改为底栏上方的深色悬浮条。

编辑模式：左边源码带行号、下方有符号快捷键，右边预览跟随「简谱 / 五线谱」与调切换；写错的行标红，点状态栏可跳到出错行。转谱文本框同样标出出错行。二胡指法打开时小节号不再压到弓法记号；谱面过宽时各行右端对齐。

演奏视图改为「自动 / 单页 / 双页 / 连续」分段按钮，小节号、二胡指法等收进「显示」菜单。声部面板的发声开关改为滑动开关。

谱库：列表加搜索与紧凑筛选，备份、WebDAV、回收站改为弹窗（设置页也可进入）；存档可以「关联 PDF / 图片」或「更换原文件」，文件会在本机谱库另存一份；多页存档显示校对进度。

练习：顶部显示本次成绩，手机上改为音名键加八度切换；换算、指法表、调音器、二胡定弦和设置页按设计稿重排，设置页新增默认音色与谱库同步入口。
