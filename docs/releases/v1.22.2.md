侧边栏改为手动折叠：电脑上「设置」右侧的按钮可收起成图标栏，再点展开，选择会被记住；不再在转谱页自动变窄。谱库、练习页标题栏去掉多余的白底；保存、复制等提示改为底部短暂提示，不再与标题重叠。

播放条显示「已播 / 总时长」和进度线，播放键图标居中；暂时不再显示乐器音域提示。

「导出 → 存为 PDF…」可选择简谱或五线谱、原调 / 音名谱 / 转调，并可勾选小节号与二胡指法弓法。开启二胡指法后，标记不再把每个音撑宽，只在相邻标记会重叠时局部加宽，谱面宽度与普通简谱接近。
