# 平台接口

`platform/browser.js`、`android.js`、`desktop.js` 注册适配器，`bridge.js` 在页面执行前选择一次。只有 Android 适配器读取 `AndroidTools`，只有桌面适配器读取 Tauri IPC。业务模块禁止判断平台原生对象；构建检查对此报错。

公共方法：

- `Platform.kind`：browser / android / desktop。
- `Platform.ready`：桌面凭据元数据加载完成；不返回密码。
- `request(method,url,headers,body,options)`：body 为 `{text}` 或 `{blob}`；返回 `{status,headers,text(),blob()}`。模型请求 options.model=true，设置 8 MB 响应限制；WebDAV 保留二进制与任意支持的方法。
- `saveBlob(blob,filename,mime)`：浏览器下载、Android 系统保存、桌面保存对话框。返回 false 表示桌面用户取消。
- `copyText(text)`、`readClipboard()`、`printScore()`、`setImmersive(on)`、`openExternal(url)` 均为异步接口。

凭据存储是同步旧配置与异步桌面系统接口之间的适配：`SecureCredentials.prepare` 在用户保存配置时先等待系统安全保存，之后核心只保存凭据标识；`requestHeaders` 等待平台就绪后发出凭据引用。`ScoreOCR.saveConfigAsync` / `ScoreLibrary.saveDavConfigAsync` 供界面保存按钮使用；旧同步加载保持 Android 配置迁移与现有算法测试兼容。浏览器只使用会话内存。

`SecureCredentials.protect` 不承担桌面异步保存，缺少准备好的凭据会失败；不会把桌面密码降级写到 localStorage。桌面同步查验只使用凭据 ID、地址、类型和用户名缓存；原生请求再次检查真实系统凭据与地址约束。

现有乐谱、存档与备份格式保持不变；本次不迁移到 SQLite，也不重写浏览器音频 / PDF。后续需要 SQLite 时可以独立替换持久层，并提供单独数据迁移。
