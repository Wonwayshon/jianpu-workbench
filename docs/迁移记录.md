# 1.20.0 项目整理

## 已完成

- 从历史 Android assets 提取 `web/` 为唯一公共源码；提取 Android 外壳到 `android/`，既有回归测试和曲谱案例归拢到 `tests/`。
- 把文件、网络、剪贴板、打印、全屏、凭据访问集中到 `platform/`；网页业务不再直接判断 Android 原生对象。
- 使用 `project.json` 管理版本、Android versionCode 和应用标识，自动生成三端资源、桌面配置与 AI 检查器。构建校验三端核心内容相同。
- Android Studio preBuild 自动同步资源；独立 Android 源码导出保留原生类、资源与完整网页。
- Tauri 2 桌面外壳接系统 WebView、系统密码存储、HTTPS 鉴权、文件保存、打印与全屏。已有 Android 与网页的存档格式、数据库名、包名和本地网页地址保持原约定。
- macOS 与 Windows 构建工作流已添加；未连接或运行远端仓库。
- 保留旧 APK / 交付文件。`work/` 中旧代码与工具属于历史工作区，后续只维护新的规范目录。原签名材料保留于私有 work，不纳入源码导出。

## 验证

16 组 JavaScript 回归通过，覆盖总谱时值 / 延长 / 反复、二胡指法、分页、装饰音、PDF 校验、存档版本、配置迁移与三端适配。HTML 内联脚本也做语法校验，CSP 哈希由构建生成。

桌面 Rust 编译与两个原生地址约束测试通过。Mac arm64 应用已成功打包，约 8.1 MiB；没有附带 JVM 或 Chromium。Android 1.20.0 已用原证书构建，并验证可覆盖 1.19.0。

本机 HTTP 预览资源加载验证通过。应用依旧支持直接浏览器使用；PWA 安装和离线缓存未纳入本次整理。

## 尚未验证

当前电脑不能产出已验证的 Windows 安装包；需 Windows runner 或实体机器执行构建。Mac 包为本地测试构建，未使用 Developer ID 签名 / Apple 公证。

未在桌面实际操作 PDF、麦克风、摄像头、系统钥匙串授权弹窗、打印对话框及长期 WebDAV 同步，也未进行 Android 真机覆盖迁移。编译 / 模拟适配测试通过不等同于这些设备功能已实测。

## 1.20.1 Mac 签名修复

确认 1.20.0 Mac App 存在完整应用签名校验失败（链接器临时签名未包含应用资源）。1.20.1 改为完整 ad-hoc 签名，并增加构建后严格校验和 DMG 容器校验；CI 使用 DMG 保存可执行权限。仍未使用 Developer ID / Apple 公证，不保证首次安装无系统确认。

修复版 1.20.1 完整 App 通过 codesign 深度严格验证；DMG 容器校验通过，已只读挂载确认镜像内 App 签名、版本、应用标识和可执行权限均正确。未绕过系统 Gatekeeper，也未执行 Apple 公证。

## 1.20.2 后台播放与公开准备

- 播放音频使用独立的定时调度；动画帧只更新谱面高亮。延迟回调跳过已经结束的音符和节拍，仍在发声的长音从对应位置继续，避免返回前台时集中补播。桌面 WebView 禁用后台节流（此原生策略由 Tauri 在 macOS 14+ 支持）。
- 移除公开源码及版本标签历史中的完整第三方曲谱，改用程序生成的测试序列；原资料与历史只保留于本机私有备份。
- 桌面编译映射个人路径；Mac 打包前检查可执行文件。补充密钥、环境变量和密码文件的忽略规则及提交前/CI 检查。检查不会打印密钥值，不能替代人工审查任意密码或第三方资料。
- 旧 GitHub 构建日志已扫描，未发现本机用户名路径、私人邮箱或已知密钥格式。

18 组核心、隐私及更新检查测试通过；后台播放回归覆盖动画暂停、延迟补播、长音续接、总谱声部/节拍同步及停止后定时器释放。上述为自动化模拟和构建验证，实际 Mac 切换应用的播放行为仍需设备交互核对。

App 页脚新增 GitHub 更新检查入口，验证官方 Release 和平台安装包链接，支持版本号比较、私有仓库/限流提示。当前为手动下载安装；私有仓库不会向未授权用户提供发布信息。
